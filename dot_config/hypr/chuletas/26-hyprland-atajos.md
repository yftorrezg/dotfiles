# 🪟 Hyprland · Ventanas, escritorios y apps

> Todos los atajos del escritorio, leídos de binds.lua. Se regenera sola con scripts/atajos-doc.py.

## 🧭 Cómo leer las teclas

- `SUPER` = sistema (ventanas, escritorios, apps). `SUPER + ALT` = apps web y estudio.
- `SUPER + SHIFT` = acciones sobre la ventana o la selección. `SUPER + CTRL` = escritorios.
- 💡 Consejo: si no recuerdas un atajo, búscalo por la letra: casi todos usan la inicial de lo que hacen.

## 🪟 Ventanas

| Atajo | Qué hace | Mnemotecnia |
|---|---|---|
| `SUPER + Q` | Cerrar la ventana enfocada | Q = Quit |
| `SUPER + ALT + Space` | Ventana flotante (alternar) | Space = la barra espaciadora |
| `SUPER + F` | Pantalla completa de la ventana | F = Full |
| `SUPER + J` | Alternar división de la ventana (split) | J = (sin mnemotecnia; solo se acuerda) |
| `ALT + Tab` | Ciclar entre ventanas | Tab = siguiente |
| `SUPER + mouse:272` | Arrastrar ventana con el mouse (mantén y mueve) | Clic izq. = mover |
| `SUPER + mouse:273` | Redimensionar ventana con el mouse | Clic der. = tamaño |
| `SUPER + Minus` | Zoom de la pantalla (alejar) | − = menos |
| `SUPER + Plus` | Zoom de la pantalla (acercar) | + = más |

## 🧭 Foco y escritorios

| Atajo | Qué hace | Mnemotecnia |
|---|---|---|
| `SUPER + Left` | Enfocar la ventana a la izquierda | Flechas = dirección |
| `SUPER + Right` | Enfocar la ventana a la derecha | Flechas = dirección |
| `SUPER + Up` | Enfocar la ventana de arriba | Flechas = dirección |
| `SUPER + Down` | Enfocar la ventana de abajo | Flechas = dirección |
| `SUPER + SHIFT + Up` | Mover la ventana hacia arriba | SHIFT = mover ventana |
| `SUPER + SHIFT + Right` | Mover la ventana a la derecha | SHIFT = mover ventana |
| `SUPER + SHIFT + Left` | Mover la ventana a la izquierda | SHIFT = mover ventana |
| `SUPER + SHIFT + Down` | Mover la ventana hacia abajo | SHIFT = mover ventana |
| `SUPER + CONTROL + SHIFT + Right` | Mandar la ventana al escritorio siguiente del monitor | CTRL+SHIFT = mover de escritorio |
| `SUPER + CONTROL + SHIFT + Left` | Mandar la ventana al escritorio anterior del monitor | CTRL+SHIFT = mover de escritorio |
| `SUPER + S` | Mostrar/ocultar el escritorio especial (scratchpad) | S = Scratchpad |
| `SUPER + SHIFT + 1` | Mandar la ventana al monitor 1 | SHIFT + número = mandar ventana |
| `SUPER + SHIFT + 2` | Mandar la ventana al monitor 2 | SHIFT + número = mandar ventana |
| `SUPER + Tab` | Ciclar ventanas del escritorio virtual actual | Tab = siguiente ventana |
| `SUPER + ALT + 1` | Enfocar el monitor 1 | ALT + número = monitor |
| `SUPER + ALT + 2` | Enfocar el monitor 2 | ALT + número = monitor |
| `SUPER + CONTROL + Right` | Escritorio virtual siguiente (todos los monitores) | CTRL + flechas = cambiar escritorio |
| `SUPER + CONTROL + Left` | Escritorio virtual anterior (todos los monitores) | CTRL + flechas = cambiar escritorio |
| `SUPER + mouse_down` | Escritorio anterior con la rueda | Rueda = escritorios |
| `SUPER + mouse_up` | Escritorio siguiente con la rueda | Rueda = escritorios |
| `SUPER + 1 … 0` | Escritorio virtual 1…10 (todos los monitores a la vez) | Número = escritorio |
| `SUPER + CONTROL + 1 … 0` | Mandar la ventana enfocada al escritorio N (mismo monitor) | CTRL + número = mandar a N |

|---|---|---|

| `SUPER + W` | Navegador (Brave) | W = Web |
| `SUPER + N` | Obsidian (notas) | N = Notas |
| `SUPER + ALT + Q` | YouTube (enfocar o abrir) | ALT + Q = YouTube (Q no tiene relación) |
| `SUPER + ALT + W` | WhatsApp Web (enfocar o abrir) | W = WhatsApp |
| `SUPER + ALT + T` | Telegram (enfocar o abrir) | T = Telegram |
| `SUPER + ALT + F` | Facebook (enfocar o abrir) | F = Facebook |
| `SUPER + ALT + I` | Instagram (enfocar o abrir) | I = Instagram |
| `SUPER + ALT + D` | Google Drive (enfocar o abrir) | D = Drive |
| `SUPER + T` | TikTok (escritorio fijo) | T = TikTok |
| `SUPER + G` | VS Code (escritorio fijo de código) | G = Código |
| `CONTROL + SHIFT + Escape` | Monitor de procesos (btop) | Ctrl+Shift+Esc = ver procesos |
| `CONTROL + ALT + Escape` | Matar LibreOffice colgado (un paso) | Ctrl+Alt+Esc = matar colgado |
| `SUPER + Z` | Ajustes de Noctalia | Z = Zona de ajustes |
| `SUPER + X` | Centro de control (sonido, red, etc.) | X = eXtra/Control |
| `SUPER + Super_L` | Buscador / lanzador (tocar SUPER solo y soltar) | Solo SUPER = buscar |
| `SUPER + period` | Lanzador en la pestaña de emojis | . = emojis |
| `SUPER + K` | Stream Deck (OpenDeck): abrir la ventana de configuración | K = Keypad (teclado de deck) |
| `SUPER + C` | Abrir el curso y los apuntes de la sesión de estudio | C = Curso (ver hoja 27) |
| `SUPER + ALT + C` | Configurar links del curso | ALT + C = Configurar curso |
| `SUPER + V` | Panel del portapapeles (historial) | V = Ver el portapapeles |
| `SUPER + A` | Panel de notificaciones | A = Avisos |
| `SUPER + ALT + E` | Ir al escritorio «estudio» (nombrado) | E = Estudio |

## 🎨 Sistema y pantalla

| Atajo | Qué hace | Mnemotecnia |
|---|---|---|
| `SUPER + L` | Bloquear la sesión | L = Lock |
| `SUPER + SHIFT + D` | Cambiar modo claro / oscuro | SHIFT + D = Dark |
| `SUPER + SHIFT + A` | Selector de estilos (temas, fondos, colores) | SHIFT + A = Apariencia |
| `SUPER + SHIFT + C` | Abrir las chuletas (esta ventana) | SHIFT + C = Chuletas |
| `SUPER + SHIFT + W` | Editar/mover los widgets del escritorio con el mouse | SHIFT + W = Widgets |
| `Print` | Captura de región (Noctalia) | Print = Impr Pant |
| `SUPER + Print` | Captura de pantalla completa (Noctalia) | SUPER + Print = todo |
| `SUPER + ALT + N` | Modo enfoque (todo negro, sin barra ni widgets) | N = eNfoque |
