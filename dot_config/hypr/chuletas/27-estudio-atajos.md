# 🎓 Estudio · Cursos, capturas, voz y descargas

> Los atajos que usas para estudiar: cursos, capturas automáticas, leer en voz alta, traducir y descargar.

## 🧭 Cómo leer las teclas

- `SUPER` = sistema (ventanas, escritorios, apps). `SUPER + ALT` = apps web y estudio.
- `SUPER + SHIFT` = acciones sobre la ventana o la selección. `SUPER + CTRL` = escritorios.
- 💡 Consejo: si no recuerdas un atajo, búscalo por la letra: casi todos usan la inicial de lo que hacen.

## 🎓 Estudio y cursos

| Atajo | Qué hace | Mnemotecnia |
|---|---|---|
| `SUPER + ALT + A` | Elegir la carpeta de un curso: capturas + apuntes de todas las clases | A = Apuntes de todo el curso |
| `SUPER + ALT + P` | Retomar apuntes tras reiniciar (las clases hechas se saltan) | P = Pendientes / Proseguir |
| `SUPER + I` | Centro de estudio: abre la próxima clase (pre-test, apuntes, práctica, tests) | I = Ir a clase |
| `SUPER + ALT + V` | Verificar (correr) los tests de la práctica de la clase actual | V = Verificar |

## 📸 Capturas

| Atajo | Qué hace | Mnemotecnia |
|---|---|---|
| `CONTROL + SHIFT + D` | Elegir la carpeta donde se guardan las capturas | D = Dónde |
| `CONTROL + SHIFT + S` | Captura y guardarla en archivo | S = Save (guardar) |
| `SUPER + ALT + S` | Auto-captura: activar/desactivar (captura al ver la clase) | S = Screenshots automáticas |
| `SUPER + ALT + Y` | Capturas de un video de YouTube | Y = YouTube |
| `SUPER + SHIFT + S` | Captura de región solo al portapapeles (sin archivo) | SHIFT + S = Screenshot (como en Windows) |

## 🗣️ Voz, traducción y resumen

| Atajo | Qué hace | Mnemotecnia |
|---|---|---|
| `SUPER + R` | Leer en voz alta el texto seleccionado (otra vez = parar) | R = Read (leer) |
| `SUPER + ALT + R` | Elegir la voz (edge-tts online o Piper offline) | ALT + R = voz de Read |
| `SUPER + SHIFT + T` | Traductor flotante EN/ES de la selección | SHIFT + T = Traducir |
| `SUPER + SHIFT + R` | Resumir la selección | SHIFT + R = Resumir |
| `SUPER + SHIFT + mouse:273` | Menú de resumen con clic derecho (con SUPER+SHIFT) | SHIFT + clic der. = menú de resumir |

## 📥 Descargas, repos y anillo

| Atajo | Qué hace | Mnemotecnia |
|---|---|---|
| `SUPER + D` | Menú de descargas (link copiado → video, 720p, MP3, lista) | D = Descargar |
| `SUPER + ALT + G` | Link de GitHub → carpeta con imágenes del código (sin IA) | G = código (GitHub) |
| `SUPER + ALT + O` | Anillo radial: mantén y elige (al soltar ejecuta) | O = anillO |
