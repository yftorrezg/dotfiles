Yafer cursa materias de universidad y complementa con cursos de Udemy y YouTube. Usa mucho Gemini como asistente de estudio (más que Claude, al menos para esto). Las fuentes de material están dispersas: páginas web, Google Drive (cuadernos), Obsidian.

Se autodefine como débil en **organización** del material/flujo de estudio — ese es el problema concreto a resolver, no falta de herramientas sino de sistema para usarlas juntas.

Quiere ir armando con ayuda (mía) una biblioteca de **prompts reutilizables para Gemini** enfocados a estudiar, por ejemplo:
- "dame más ejemplos"
- "enséñame paso a paso"
- "hazme 3 preguntas para ver si entendí el tema"

La idea es iterar esto con el tiempo, cada vez más específico a su día a día, no resolverlo todo de una.

**Metas a más largo plazo** (no urgentes todavía, no tiene tiempo aún):
- Grabar TikToks mostrando proyectos propios de IA / computer vision para darse a conocer y conseguir mejores oportunidades laborales — usaría OBS para grabar (ver [[mirabox-migracion-companion]] y el resto de `CLAUDE.md` de este repo para el setup de StreamDeck, que es donde puede terminar controlando OBS desde un botón físico más adelante).
- Inglés es importante para él (probablemente ligado a las metas de oportunidades laborales / contenido).

**Cómo ayudar**: cuando retome el tema de organización de estudio, no proponer una solución completa de entrada (vault de Obsidian gigante, sistema de prompts completo, etc.) — preguntar primero qué quiere atacar primero, dado lo disperso del problema (materias, cursos, notas, prompts son 4 frentes distintos).
